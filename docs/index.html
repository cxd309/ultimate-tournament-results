🥏 Ultimate Tournament Results

Historic archive of ultimate tournament results, recorded using the Live! by BULA API.

View on GitHub

Why?

Live! by BULA is the public results platform used by recent WFDF, EUC and BULA events. It serves an API to provide dynamic data for the frontend as cached JSON files. However, this data is not guaranteed to be hosted forever.

This project aims to provide a long term archive of tournament statistics for the general use of ultimate data enthusiasts.

How?

This project includes a GO based tool that fetches data from a Live! deployment and attempts to recreate the underlying database from the available information in a sqlite archive file (archive). It can then recreate the JSON files for the API and serves them with GitHub Pages (publish).

This should mean that any applications/tools designed to work with a current Live! API should continue to work if redirected to this archive as a drop-in replacement.

It also provides a second usage method of direct sqlite access. This would probably be more useful for those who want to run some data analytics.
